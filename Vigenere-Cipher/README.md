Vigenere Cipher

Overview:
A Java Swing application that implements the Vigenère Cipher encryption algorithm. The application allows users to encrypt and decrypt text using a custom key through an interactive graphical user interface (GUI).

Features:
- Text Encryption
- Text Decryption
- User-Defined Key Support
- Graphical User Interface (Swing)
- Input Validation
- Preservation of Non-Alphabetic Characters

Technologies Used:
- Java
- Java Swing
- Object-Oriented Programming (OOP)

Learning Outcomes:
- Classical Cryptography
- Encryption and Decryption Techniques
- GUI Development with Java Swing
- String Manipulation and Character Processing
