Message Digest (SHA-256 & SHA-512)

Overview:
Java implementation of SHA-256 and SHA-512 hashing algorithms for generating message digests and verifying data integrity.

Features:
- SHA-256 Hash Generation
- SHA-512 Hash Generation
- Hexadecimal Output
- Byte Array Representation
- Digest Length Analysis

Technologies Used:
- Java
- MessageDigest API
- SHA-256
- SHA-512

Learning Outcomes:
- Cryptographic Hash Functions
- Data Integrity Verification
- Message Digest Generation
- Secure Hash Algorithms
